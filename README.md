# ☕ Java Programming & Web Technologies Practicals Portal

A modern, responsive, high-contrast client-side web application showcasing complete laboratory experiments for **Full Stack Java Programming (FSJP) & Web Technologies** (Final OR/PR Exam). The portal features syntax-highlighted Java (JDK 21+) and JavaScript (ES6+) source codes, runtime complexity profiles, theoretical background, learning outcomes, authentic execution screenshots directly sourced from laboratory write-ups, and an interactive in-browser playground with live embedded web applications (Stopwatch, Email Validator, DOM Color Changer).

---

## 🚀 Quick Start

### Option 1: Open Directly in Browser
Double-click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari). No web server, Node.js, or external build dependencies are required.

### Option 2: Run Local Dev Server (with Live-Reload)
```bash
npm run dev
# or
node dev-server.js
```
The local server will launch at [http://localhost:3000](http://localhost:3000) with automatic hot-reloading on file modifications.

## 🛠️ Key Features

- **Split & Stacked Views:** Toggle between side-by-side view (Code on left, execution output on right) or stacked view, code-only, or output-only.
- **Triple Output Display:**
  - **Actual Screenshot:** High-resolution authentic screenshots of terminal compilation sessions and browser outputs.
  - **Console View:** Crisp, monospace terminal execution logs with exit codes and execution summaries.
  - **Live Interactive App:** Direct client-side embedded widgets for Experiments 4, 5, and 6:
    - *Exp 4:* Working millisecond-precision digital stopwatch with Start, Stop, and Reset.
    - *Exp 5:* Interactive email validation input with diagnostic verification of `@` and `.` characters.
    - *Exp 6:* Automatic 5-second DOM background color cycling box with real-time countdown progress bar.
- **Interactive Playground / Simulator:** In-browser execution engine simulating Java OOP concepts and live client-side DOM/JavaScript behavior.
- **Accessible 1-Click Code Copy:** Instant clipboard copying for all Java and JavaScript programs with fallback for `file:///` contexts.
- **Zoomable Lightbox:** Click any output screenshot for full-screen inspection with zoom (+/-), pan, navigation, and download.
- **Search & Category Filters:** Real-time search across titles, code keywords, and concepts with keyboard shortcut (`/` to search).
- **Dark & Light Mode:** High-contrast pure monochrome theme with automatic system preference detection and local storage persistence.
- **Print / PDF Ready:** Formatted `@media print` layout for physical lab journals or PDF generation.
